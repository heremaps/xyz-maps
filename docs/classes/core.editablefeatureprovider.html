    Class EditableFeatureProviderAbstract

    EditableFeatureProvider is an abstract FeatureTileProvider that can be edited using the Editor module.

    The editor needs to know how to interpret the data of a feature. Which methods have to be implemented depends on the feature class:

    • 'LINE', 'MARKER' and 'AREA' are detected by geometry type and need no additional methods.
    • 'NAVLINK', 'PLACE' and 'ADDRESS' require detectFeatureClass to be overridden.
    • 'PLACE' and 'ADDRESS' additionally require the routing methods, e.g. readRoutingPosition, readRoutingLink, writeRoutingPosition, writeRoutingLink and readRoutingProvider.
    • 'NAVLINK' features require the attribute readers and writers of the navlink, e.g. readDirection and readZLevels, as well as the turn restriction methods.

    detectFeatureClass

    • detectFeatureClass(feature: Feature): string

      This method is used to determine the FeatureClass required to edit the feature. The FeatureClass defines how a certain feature behaves when its getting edited.

      By default, the Editor handles all features of geometry type 'LineString' as Line, 'Point' as Marker and '(Multi)Polygon' as Area.

      If you want to edit features with FeatureClass 'NAVLINK', 'PLACE' or 'ADDRESS' this method must be overridden to enable editing of Navlinks, Places or Addresses. The other methods required for each feature class are listed in the class documentation of EditableFeatureProvider.

      Parameters

      • feature: Feature

        The feature whose FeatureClass is requested

      Returns string

      the FeatureClass of the feature, or null if the feature should not be editable.

    OptionalreadConnectedLinks

    • readConnectedLinks?(
          link: Feature,
          index: number,
      ): { index?: number; link: string | number }[] | []

      Read intersection-related connectivity for a Navlink node.

      This method allows an EditableFeatureProvider to override the default geometric intersection detection.

      It is called for the start or end node of a Navlink to determine whether that node forms an intersection and which Navlinks are connected to it.

      Implement this if intersection information is stored in feature properties, derived from external metadata, or otherwise known in advance.

      Return values:

      • undefined → No custom information is provided. The editor falls back to geometric intersection detection.

      • [] (empty array) → Explicitly no connected links at this node. The editor will NOT perform geometric detection.

      • [ { id, index? }, ... ] → Explicitly defined connected Navlinks, referenced by their feature ID. If index is omitted, the editor automatically determines the corresponding node coordinate of the connected link.

      Parameters

      • link: Feature

        The Navlink feature whose node connectivity is being read.

      • index: number

        The coordinate index of the node (0 → start node, last coordinate → end node).

        Note: Regardless of the returned value, geometric requirements for intersection (such as spatial proximity and coordinate precision) must still be fulfilled. See the intersectionScale property for details.

      Returns { index?: number; link: string | number }[] | []

      An array of { id: string | number; index?: number }, an empty array to signal "no connection", or undefined to fall back to default detection.
