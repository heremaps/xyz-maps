    faces

    faces: {
        count?: number;
        geometryIndex: number;
        material: string;
        start?: number;
    }[]

    The Faces of the Model. The winding orientation is counter-clockwise.

    Type Declaration

    • Optionalcount?: number

      A number specifying the number of indices of the face to be rendered. If "count" is defined, "index" is ignored.

      Default Value

      position.size/3
    • geometryIndex: number

      Index of the geometry used to render the face.

    • material: string

      The name of the Material the geometry should be rendered with. If the used material is not defined in Materials, or none is defined, the default material will be used.

    • Optionalstart?: number

      A number specifying the starting index of the vertices to render the face. If "start" is defined, "index" is ignored.

      Default Value

      0
