    decodeBase64

    • decodeBase64(encoded: string): Uint8Array

      Decode standard base64 into bytes using native atob validation. ASCII whitespace and omitted padding are accepted; invalid alphabet or padding throws. This does not decode text or accept base64url.

      Parameters

      • encoded: string

      Returns Uint8Array

    • decodeTga(bytes: Uint8Array): ModelTextureData

      Decode an uncompressed or RLE-compressed 24/32-bit truecolor TGA image into ModelTextureData, with bottom-to-top RGBA rows and flipY: false. Throws an Error for invalid or unsupported input.
